## LangChain SIBA ChatBot  

### 📌 Project Description  
The **LangChain SIBA ChatBot** is designed to assist students with information about **IBA Sukkur University**. Instead of searching on Google, students can simply interact with this chatbot to get instant answers related to university policies, courses, and other academic information.  

### ✨ Features  
- 🗨️ **Online Chatbot** – Provides quick and accurate responses.  
- 🎯 **University-Specific Assistance** – Focused on IBA Sukkur details.  
- 🔍 **Instant Queries Resolution** – No need to browse multiple web pages.  

### 🚀 Installation Instructions  
- No installation required! The chatbot is available online for instant use.  

### 🔧 Usage  
1. Open the chatbot interface.  
2. Type your question or query.  
3. Get immediate responses related to **IBA Sukkur**.  

### 🛠 Technologies Used  
- **LangChain** – For implementing Large Language Model (LLM) capabilities.  
- **Streamlit** – For building the web-based chatbot UI.
